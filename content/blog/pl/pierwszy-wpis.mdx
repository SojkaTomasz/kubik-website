Ten wpis jest przykładem warstwy treści. Skasuj go, kiedy zaczniesz pisać własne — ale najpierw
zajrzyj, jak jest zbudowany.

## Co podmienić na start

Trzy pliki wystarczą, żeby starter przestał być starterem:

1. `src/site.config.ts` — nazwa, opis, adres, języki
2. `src/company.config.ts` — dane firmy trafiające do JSON-LD
3. `src/app/theme/brand.css` — rampa kolorów marki

## Frontmatter jest sprawdzany

Nagłówek każdego pliku przechodzi przez schemat zod **przy budowaniu**. Literówka w nazwie pola albo
brakująca data wywracają build z nazwą pliku w komunikacie — zamiast dawać pustą stronę na
produkcji.

> Pole `draft: true` chowa wpis w produkcji, ale zostawia go widocznym w trybie deweloperskim.
> Wygodne do pisania na spokojnie.

## Zwykły Markdown też działa

Tabela, kod, lista — wszystko, czego można oczekiwać:

| Element  | Skąd pochodzi    |
| -------- | ---------------- |
| Nagłówki | `typography.tsx` |
| Odstępy  | `--spacing-*`    |

```ts
import { allPosts } from '@/lib/content/posts'

const latest = allPosts('pl').at(0)
```

Style tekstu biorą się z jednego miejsca — komponentu `Prose`. Zmiana tam przenosi się na każdy wpis
naraz.
